## 🗂️ Estructura del Repositorio

El proyecto está dividido en dos grandes bloques para mantener el código limpio y organizado:

* 📁 **`Back-end/`**: Contiene mis algoritmos y lógica principal en **Java** (utilizando *IntelliJ IDEA*). Aquí verás reflejados conceptos de Introducción a la POO, Interfaces y pequeños juegos de lógica.
* 📁 **`Front-end/`**: Dedicado a la maquetación web con **HTML/CSS y JavaScript** (utilizando *VS Code*), enfocado en crear interfaces limpias y funcionales.
